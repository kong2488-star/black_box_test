# Coarse Probe 사람 검토 기록

Coarse 모델의 탐색 결과를 사람이 원본 영상에서 확인한 기록이다.
모델 실행 원본인 `probe_runs.jsonl` 및 파생 리포트인 `probe_report.md`와 분리해 관리한다.
Fine 쪽 기록은 `fine_probe_human_reviews.md` 에 있다.

**이 파일이 필요한 이유.** `probe_runs.jsonl` 은 모델이 무엇을 말했는지만 담는다.
모델이 **말하지 않은 것**(놓친 사건)은 정의상 그 파일에 줄이 생기지 않으므로,
사람이 원본을 보고 따로 적지 않으면 영영 기록되지 않는다.
